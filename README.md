# ⚛️ Portfolio 2025

Guillem Leon's personal portfolio

---

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/guillemleon/portfolio.git
cd portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run start
```

### 4. Build for production

```bash
npm run build
```
