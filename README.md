---

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/guillemleon/portfolio.git
cd portfolio
```

### 4. Install dependencies

```bash
npm install
```

### 5. Start development server

```bash
npm run start
```

### 6. Build for production

```bash
npm run build
```
